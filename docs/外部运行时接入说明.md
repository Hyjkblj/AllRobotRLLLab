# 外部运行时接入说明

平台进程只负责编排、状态机、对象存储和队列；GMR、GVHMR、Isaac Lab 和 Unitree MuJoCo 在各自的 Python/CUDA 或 C++ 环境中运行。运行器之间只通过文件产物、JSON manifest 和 SHA-256 交换数据。

## 环境边界

| 运行时 | 必要环境 | 平台配置 |
| --- | --- | --- |
| GMR | Python 3.10、MuJoCo、Mink、SMPL-X | `GMR_PATH`、`GMR_PYTHON` |
| GVHMR | Python 3.10、Torch 2.3/cu121、checkpoint | `GVHMR_PATH`、`GVHMR_PYTHON` |
| Isaac Lab/RSL-RL | Isaac Sim 5.1、Isaac Lab 2.3、Torch 2.7/cu128 | `ISAACLAB_PATH`、`ISAACSIM_PATH`、`ISAAC_PYTHON` |
| Unitree RL Lab | 安装在 Isaac Lab 环境中的 `unitree_rl_lab` | `UNITREE_RL_LAB_PATH` |
| Unitree MuJoCo | MuJoCo 3.3.6、`unitree_sdk2`、G1 controller | `UNITREE_MUJOCO_PATH`、`SIM2SIM_PYTHON` |

G1 MJCF 必须与 `adapters/unitree_g1_29dof/robot_spec.json` 的 joint/body 顺序一致，并通过 `G1_MJCF_PATH` 配置。生产环境没有该配置时，动作编译会被拒绝，不会退回根位姿复制。

## 注册与检查

初始化运行目录：

```powershell
python tools/robotlab.py init --mode local_file
```

注册外部 checkout（示例）：

```powershell
python tools/robotlab.py runtime register gmr --path D:/runtime/GMR --python D:/envs/gmr/python.exe --revision bb1bbe4
python tools/robotlab.py runtime register gvhmr --path D:/runtime/GVHMR --python D:/envs/gvhmr/python.exe --revision 6ec3ca3
python tools/robotlab.py runtime register isaac_lab --path D:/runtime/IsaacLab --python D:/envs/isaaclab/python.exe --revision 3c6e67bb5
python tools/robotlab.py runtime register unitree_mujoco --path D:/runtime/unitree_mujoco --revision ae6a840
python tools/robotlab.py runtime doctor --runtime-dir runtime
```

当第三方目录是当前项目 `third_party` 下的源码快照、没有独立 `.git` 时，省略 `--revision` 会自动记录目录内容哈希 `content:<sha256>`，之后目录内容发生变化会被标记为 `NOT_READY`。生产建议使用独立 checkout 并锁定上游 commit。

API 侧同样提供：

```text
GET /api/v1/runtime/doctor
```

## 业务链路

1. 上传动作或视频，API 在对象存储中写入版本并由 `asset-io` worker 校验 SHA-256。
2. `motion-cpu` worker 对 G1 轨迹直接读取；对视频依次调用 GVHMR 和 GMR，生成 `retarget_motion.pkl/npz`。
3. `MuJoCoKinematicsCompiler` 对每帧设置 qpos/qvel，调用 `mj_forward` 生成 `body_pos_w`、`body_quat_w`、线速度和角速度，发布 `TrainMotionNPZ`。
4. `isaac-gpu` worker 调用 Unitree RL Lab 的训练入口，持久化 checkpoint、指标和运行 manifest。
5. 导出阶段调用 Isaac/Unitree 导出命令并生成策略包；`sim2sim-gpu` 对三个不同 seed 调用 Unitree MuJoCo，收集视频、曲线、控制参数和 metrics。
6. 只有三个 seed 均通过阈值、产物 checksum 和 manifest 校验，运行才会进入 `READY_TO_DOWNLOAD`。

## 生产验收

环境检查通过不代表训练成功。服务器验收至少需要：

```powershell
python scripts/collect_runtime_manifest.py --root . --strict
python scripts/check_external_runtime.py --json
python tools/robotlab.py runtime doctor --runtime-dir runtime
```

随后用真实视频或 G1 动作完成一次上传、GVHMR/GMR、MuJoCo 编译、Isaac train/play/export 和三 seed sim2sim。任何 `RUNTIME_*`、`KINEMATICS_*`、`ISAAC_*` 或 `SIM2SIM_*` 错误都应在对应阶段失败并保留日志，而不是降级到 fake smoke。
