# P1 编辑与奖励配置实现说明

P1 在 P0 契约基础上增加服务器权威的动作编辑和 Reward Builder 版本链。

## 动作编辑

`backend/app/application/motion_editor.py` 提供 `MotionEditor` 和
`MotionEditVersionStore`：

- 全局平移、绕 Z 轴 yaw、时间缩放和线性/SLERP 重采样；
- 关节范围偏移、关键帧覆盖与关键帧间插值；
- 真实 `RobotSpec` 关节顺序、DoF、限位、有限值、零四元数、根部穿地和速度门禁；
- 速度和加速度统计写入质量报告，超过阈值返回 WARNING；硬限位、穿地和非有限值仍为 BLOCKED；
- IK 目标必须经过服务器注册的 `IKSolver`，未注册时返回稳定的
  `IK_SOLVER_UNAVAILABLE`，不会把浏览器临时姿态直接送入训练；
- 编辑配置只生成不可变 `MotionEditVersion`，原始动作数组不被修改。

API：

- `POST /api/v1/motion-edits`
- `GET /api/v1/motion-edits/{version_id}`
- `GET /api/v1/motions/{source_motion_version_id}/edits`
- `POST /api/v1/motion-edits/{version_id}/compile`
- `POST /api/v1/motion-edits/{version_id}/restore/{target_version_id}`

P1 的 compile 请求接受 CPU 测试用的小型数组并返回质量报告和数组摘要；正式大对象写入仍由后续对象存储/worker 阶段完成。

## Reward Builder

`reward_catalog.py` 增加参数类型、未知参数、最小/最大值、权重范围和安全终止校验。`RewardConfigVersionStore` 生成带 canonical SHA-256 的不可变版本，并支持 parent version 链。

API：

- `POST /api/v1/reward-configs`
- `GET /api/v1/reward-configs/{version_id}`
- `GET /api/v1/reward-templates/{template}/versions`
- `POST /api/v1/reward-configs/validate`

## 训练配置约束

`training_validator.py` 校验任务是否由 G1 adapter 注册、动作模式/缩放、控制周期和 GPU 数量，并提供 `resume_is_compatible` 区分结构字段和实验字段。

当前版本存储使用线程安全内存实现，P2 接入 PostgreSQL 时保留相同 application port，不改变 API/domain 契约。
