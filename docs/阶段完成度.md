## 本轮新增

- `POST /api/v1/runs/{id}/train|export|sim2sim` 支持 `X-Execution-Mode: async`，返回 HTTP `202` 和 `TaskSubmission`。
- `P3DispatchService` 负责任务校验、队列选择和 SHA-256 幂等键。
- `P3TaskExecutor` 与稳定 Celery task names：`allrobotrl.p3.train`、`allrobotrl.p3.export`、`allrobotrl.p3.sim2sim`；`backend.app.workers.celery_app` 提供可直接启动的 worker entrypoint。
- PostgreSQL UoW 已支持 project/member、Run/Attempt、SSE event、audit、outbox、asset/version 和 artifact 元数据；`users.external_id` 映射外部身份，`run_idempotency` 持久化幂等键。
- 默认 `sync_smoke` 仍用于本地契约测试；生产异步模式必须接入 Redis/Celery 和持久化 repository。
